# Creature art parts

Every creature sprite is generated by `js/sprites.js` from its species data (`types`, `look.stage/form/feat`) and an art config, read in this order: the built-in table `C` (ids 1–25), then `G.CREATURE_ART[id]`. With no config at all, a default is derived from the species' types (see `TYPE_ART` in `js/sprites.js`). Unknown values fall back to the plain look and never throw. Invalid colours are ignored. Sprites are cached after the first draw.

Stage (`look.stage` 1–3) makes parts bigger and adds detail: more petals, tines, tentacles, gears and so on. Each sprite is scaled to fit its 256x256 canvas automatically, feet at about 95%.

## Colours
| Key | Use |
| --- | --- |
| `main` | Body colour (defaults to the first type's colour) |
| `belly` | Belly or chest patch. `null` means none (defaults to a pale `main`) |
| `acc` | Accent colour: shells, fins, petals, rings, scarf, bow, gems, armour (defaults to the second type's colour) |
| `face` | Head and face colour, when it differs from `main` |
| `iris` | Lower colour of the eyes |
| `cheek` | Blush colour |
| `boltCol` | Colour of the `bolt` tail |
| `spots` | Spots on the `cater` body and on `mushroomSpots` |
| `leafCol` | Leaves on the leaf ear, tail, wing, skirt, crown and flower body (default `#6cc850`) |
| `flameCol` | Colour of the `flame` tail |
| `wingCol` | Colour of the `fairy`, `dragon` and `ice` wings |
| `hornCol` | Colour of the new horns |
| `finCol` | Colour of the `fin` ear |
| `earCol` | Colour of the `droopy` ear |
| `petalCol`, `armorCol`, `scarfCol`, `gearCol`, `bowCol`, `crownCol`, `gemCol`, `tentCol`, `sparkleCol`, `smokeCol`, `bubbleCol`, `flowerCol` | Colour of the matching flag |

## `body`
| Value | Description |
| --- | --- |
| *(default)* | Round body. A stage-1 `round` form merges head and body into one ball |
| `drop` | Water-drop teardrop, head and body merged |
| `rock` | Lumpy faceted boulder with cracks and speckles |
| `fluff` | Scalloped, fluffy outline on the body and head |
| `cater` | Caterpillar segments curling up behind the head |
| `beetle` | Glossy domed wing-case with small side legs |
| `wisp` | Ghostly flame-topped head with a curling wisp tail; floats |
| `fish` | Chubby oval fish with a dorsal fin, front fins and soft scales. Floats with no legs; default tail `fish` |
| `serpent` | Two stacked coils and a long neck, with a tail tip peeking out. No legs |
| `jelly` | Translucent jellyfish bell with a scalloped rim and a glow. Floats; tentacles are on by default |
| `golem` | Blocky stone body and head, a glowing rune in `acc`, block legs and big fists (always) |
| `shroom` | Mushroom: a big spotted cap in `main` over a stalk (`face`, or `belly`) that carries the face |
| `crystal` | Faceted gem body with light and dark facets and crystal shards on the sides |
| `dragon` | Separate head with a snout and nostrils, ridged belly, legs and claws, spines in the back view. Default tail `lizard`; add `wing` for wings |
| `blob` | Gooey slime with drips, a puddle base and bubbles inside |
| `bird` | Round egg body with a head tuft. Defaults: beak, `bird` wings, `feather` tail, bird feet |
| `flower` | Small stem body with leaf arms; the head has a ring of petals in `acc` |
| `cloud` | Puffy floating cloud with little side puffs |
| `shell` | Snail: a soft foot with a spiral shell in `acc` behind the head (in front of it in the back view) |

## Other part keys
| Key | Values and description |
| --- | --- |
| `leaf` | `sprout` (a sprout on the head), `hood` (a leaf hood), `tree` (a small tree on the back) |
| `fin` | `side`, `head`, `crest`. Needs the look feature `fin` |
| `antenna` | `ball` or `feather` (also turned on by the look feature `antenna`) |
| `spikes` | `collar` (a ring of spikes round the neck). The look feature `spikes` adds back spikes |
| `mouth` | `smile` (default), `cheeky`, `fang`, `open`, `cat`, `beak`, `teeth`, `wisp`, `grin`. Unknown values become `smile` |
| `eye` | `normal`, `fierce` (angled brows), `sleepy`, `glow`, `round` (big round eyes), `happy` (closed ^ ^ arcs), `star` (star-shaped shine) |
| `eyeAsp`, `eyeR`, `eyeY` | Numbers: eye height/width ratio, eye size relative to the head, vertical eye position |

## Look features (`look.feat`)
`ears`, `tail`, `bolt`, `wings`, `horns`, `legs`, `arms`, `fin`, `flame` (a flame on the head), `spikes` and `antenna` change the drawing. `leaf` and `fangs` are descriptive only; use the `leaf` key or the `fang` mouth to draw them. A config style always wins over a feature's default style.

The gallery of every new option is drawn by `/tmp/claude-0/artparts/gallery.js`.
